# docx2pdf — DOCX → PDF для препресса

Конвертирует Word-документ в PDF так, что **вёрстка остаётся на 100% «родной» от Word**, а **растровые изображения сохраняются без потерь** — в исходном качестве из DOCX, без JPEG-пережатия.

## Проблема

При экспорте в PDF Word пережимает фотографии в JPEG и даунсемплит их под печатное разрешение. Для препресса и типографии это неприемлемо: качество вложенных изображений теряется безвозвратно, повторная конвертация не помогает.

## Решение

Скрипт делает конвертацию в два прохода:

1. **Экспорт самим Word** через COM (`ExportAsFixedFormat`, `wdExportOptimizeForPrint`). Пагинация, колонтитулы, колонки, разрывы, шрифты, ссылки, закладки и теги структуры — всё создаёт сам Word, поэтому результат пиксельно совпадает с эталонной вёрсткой.
2. **Repair-проход** по готовому PDF (PyMuPDF): каждый растровый объект внутри PDF находится, сопоставляется с оригиналом из `word/media/*` (по уменьшенным превью, допуск по средней разнице), и подменяется на исходник:
   - если картинка не обрезалась и без эффектов — вставляются **байт-в-байт те же данные** из DOCX, нулевая перекодировка;
   - иначе — обрезка по видимой области (`a:srcRect`) без потерь, коррекция яркости/контраста (`a:lum`) в полном разрешении и сохранение в PNG/Flate (lossless).

Векторная графика (EMF/WMF/SVG) остаётся вектором, её Word и так не портит.

## Требования

- Windows (нужен установленный Microsoft Word — используется COM)
- Python 3.10+
- `pywin32`, `pymupdf`, `Pillow`, `numpy`
- JPEG XR (`.wdp`/`.jxr`) декодируется через Windows WIC + PowerShell, без сторонних библиотек

## Использование

```bash
python docx2pdf.py report.docx                 # -> report.pdf рядом с источником
python docx2pdf.py a.docx b.docx -o out/       # пакетная конвертация в out/
python docx2pdf.py report.docx --audit         # отчёт по кодекам изображений в PDF
python docx2pdf.py report.docx --pdfa          # экспорт в PDF/A-1b
python docx2pdf.py report.docx --no-repair     # оставить кодирование Word как есть
python docx2pdf.py report.docx -v              # список каждого восстановленного изображения
```

Поддерживаются `.docx`, `.doc`, `.rtf`, `.odt`; repair-проход применяется только к `.docx`.

## Проверка результата

`audit()` (и флаг `--audit`) классифицирует каждый поток изображения в PDF: байт-в-байт JPEG из DOCX / lossless Flate / перекодированный.

```bash
python verify.py book.docx raw-word.pdf final.pdf   # сверка с нетронутым экспортом Word
python verify.py book.docx final.pdf                # только аудит изображений
```

`verify.py` доказывает, что repair изменил пиксели **только внутри прямоугольников изображений**, а геометрия страниц и извлечённый текст идентичны экспорту Word.

```bash
python selftest.py
```

`selftest.py` собирает синтетический DOCX с несжатым PNG-шумом (худший случай для lossy-кодеков), конвертирует его и утверждает, что картинка в PDF пиксельно идентична исходной и перекодирования не было.

## Ограничения

- Совпадение PDF-объекта с оригиналом — эвристика по превью; при нескольких идентичных картинках возможна подмена на эквивалентную.
- Воспроизводятся кроп (`a:srcRect`) и яркость/контраст (`a:lum`); прочие эффекты (цветокоррекция, художественные эффекты) берутся из рендера Word.
- Полутоновые/CMYK/с маской изображения не трогаются: Word хранит их без потерь.
- Без установленного Word скрипт не работает.
